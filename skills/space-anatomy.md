# Construct space — anatomy

What a Construct space looks like on disk and how the pieces fit together. Verified against `~/Spaces/space-notes` (CLI v1.7.5).

## Canonical layout

```
my-space/
├── space.manifest.json     ← identity + nav + pages + toolbar + widgets + actions
├── package.json            ← deps; install with `bun install`
├── bun.lock
├── tsconfig.json
├── vite.config.ts
├── README.md
├── CONSTRUCT.md            ← optional: instructions for the in-space agent
├── config.agent            ← optional: agent runtime config
├── agent/
│   ├── config.md           ← agent persona / behavior
│   ├── skills/default.md   ← in-space agent skills
│   └── hooks/safety.json   ← optional hooks
├── src/
│   ├── entry.ts            ← GENERATED by `construct build` — don't hand-edit
│   ├── actions.ts          ← exported actions (toolbar buttons + agent tools)
│   ├── models/             ← graph models
│   │   ├── index.ts        ← re-exports
│   │   └── Foo.ts          ← one model per file
│   ├── pages/
│   │   ├── index.vue       ← matches manifest pages[].path = ""
│   │   └── settings.vue    ← matches pages[].path = "settings"
│   ├── composables/        ← Vue composables (useFoo)
│   └── widgets/
│       └── summary/
│           ├── 2x1.vue
│           └── 4x1.vue
└── tests/                  ← optional
```

## space.manifest.json — canonical shape

```json
{
  "id": "my-space",
  "name": "My Space",
  "version": "0.1.0",
  "description": "What this space does",
  "author": { "name": "Your Name" },
  "icon": "i-lucide-box",
  "scopes": ["app"],
  "projectAware": false,
  "minConstructVersion": "0.7.0",
  "navigation": {
    "label": "My Space",
    "icon": "i-lucide-box",
    "to": "my-space",
    "order": 100
  },
  "pages": [
    { "path": "", "label": "Home", "icon": "i-lucide-home", "default": true },
    { "path": "settings", "label": "Settings", "icon": "i-lucide-settings" }
  ],
  "toolbar": [
    { "id": "my-space-new", "icon": "i-lucide-plus", "label": "New", "action": "createItem" }
  ],
  "keywords": ["my-space"],
  "agent": "agent/config.md",
  "skills": ["agent/skills/default.md"],
  "actions": "src/actions.ts",
  "widgets": [
    {
      "id": "summary",
      "name": "Summary",
      "description": "Quick summary",
      "icon": "i-lucide-box",
      "defaultSize": "4x1",
      "sizes": {
        "2x1": "widgets/summary/2x1.vue",
        "4x1": "widgets/summary/4x1.vue"
      }
    }
  ]
}
```

## Rules

- `scopes` is ALWAYS a plural array. Valid values: `"app"` (desktop sidebar), `"org"` (org workspace). Combine: `["app", "org"]`.
- Manifest `pages[].path` has **no leading slash**. Use `""` for index, `"settings"` not `"/settings"`. Leading slashes break entry.ts.
- `toolbar[].action` must match an exported action in `src/actions.ts`.
- `icon` strings use the `i-lucide-` prefix.
- `widgets[].sizes` keys are `WxH` strings (`"2x1"`, `"4x1"`); values are Vue file paths relative to space root.
- `id` is the URL slug and must be unique in the marketplace.

## Build / install / publish flow

```bash
bun install
construct build         # generates src/entry.ts and runs Vite
construct install       # installs into the local Construct spaces dir
construct dev           # watch mode
construct validate      # checks manifest
construct check         # vue-tsc + eslint
construct publish       # publishes to registry (--bump patch|minor|major)
```

Reverse a publish target: `construct publish --private` or `--public`.

## Pages

A page in `pages[]` maps to a file at `src/pages/<path>.vue` (or `src/pages/index.vue` for empty path).

A page is a normal Vue 3 SFC:

```vue
<script setup lang="ts">
import { useGraph } from '@construct-space/graph'
import { Note } from '../models/Note'

const notes = await useGraph(Note).find()
</script>

<template>
  <div class="p-4">
    <h1 class="text-2xl">Notes</h1>
    <ul>
      <li v-for="n in notes" :key="n.id">{{ n.title }}</li>
    </ul>
  </div>
</template>
```

## Widgets

Widgets render on the Construct home screen / sidebar. Each size is its own Vue SFC. Smaller sizes (`2x1`) get less content, larger (`4x1`, `4x2`) get more.

Convention: widgets show *read-only summary state*; clicking opens the full space.
